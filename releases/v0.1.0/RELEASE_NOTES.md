# HUFS BAI Legal Embed 1B v0.1

## English

A Korean legal-domain embedding model by **HUFS Business AI Lab, Hankuk University of Foreign Studies**, fully fine-tuned from NVIDIA Nemotron-3-Embed-1B-BF16. It produces 2,048-dimensional embeddings for legal passage search and RAG retrieval.

**nDCG@10: 0.8293**, compared with **0.7895** for the original model, a **5.04% relative improvement**. Recall@10 is **95.0%**. These results use 500 development queries and 66,895 passages on the same RTX A6000. The nDCG gain's paired document-group bootstrap 95% interval is **[+0.0221, +0.0581]**. The reserved test set has not been evaluated.

Download the complete FP32 model without a token or subscription:

```bash
git clone https://github.com/juho127/hufs-bai-embedding-models.git
cd hufs-bai-embedding-models
python scripts/download_release.py --output models/hufs-bai-legal-embed-1b-v0.1
```

After [installing the inference environment](https://github.com/juho127/hufs-bai-embedding-models/blob/v0.1.0/docs/setup.md):

```bash
python examples/retrieve.py --model models/hufs-bai-legal-embed-1b-v0.1
```

The downloader checks SHA-256 hashes and restores the model directory. **The source-code ZIP and tar.gz generated by GitHub do not contain the weights.** Use the downloader or the model assets listed in `manifest.json`.

## 한국어

**한국외국어대학교 비즈니스AI연구실**의 한국어 법률 검색 임베딩 모델입니다. NVIDIA Nemotron-3-Embed-1B-BF16의 전체 파라미터를 학습했으며, 법률 근거 문단 검색과 RAG에 사용할 수 있는 2,048차원 벡터를 생성합니다.

원본 대비 **nDCG@10이 0.7895에서 0.8293으로 상대 5.04% 향상**됐고, Recall@10은 **95.0%**입니다. 같은 RTX A6000에서 검증 질문 500개와 후보 문단 66,895개로 평가했습니다. nDCG 개선량의 문서군 단위 bootstrap 95% 신뢰구간은 **[+0.0221, +0.0581]**이며, 별도로 보류한 test는 아직 평가하지 않았습니다.

위 다운로드 명령으로 토큰이나 구독 없이 전체 FP32 모델을 받을 수 있습니다. 스크립트가 SHA-256과 파일 크기를 검증하고 모델 폴더를 구성합니다. **GitHub가 자동으로 제공하는 Source code ZIP과 tar.gz에는 가중치가 없습니다.** 다운로드 스크립트 또는 `manifest.json`에 나열된 모델 파일을 사용하세요.

No concatenation or separate base model is needed. All 146 FP32 tensors and synthetic Korean embeddings match the original evaluated checkpoint exactly.
